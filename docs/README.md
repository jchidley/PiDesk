# PiDesk documentation

This directory separates current architecture, design assessment, development instructions, and planned work.

- [Architecture](architecture.md) — how the WinUI process provides a graphical alternative to Pi's TUI through RPC.
- [Design review](design-review.md) — current strengths, defects, and assessment of the Microsoft WinUI skills.
- [Pi TUI capability gap review](tui-gap-review.md) — evidence-based comparison with Pi 0.85.0, including what to migrate, adapt, or deliberately exclude.
- [Improvement plan](improvement-plan.md) — canonical ordered milestones and acceptance criteria.
- [Development](development.md) — build, run, and test the application.
- [Pi 0.85.0 adoption audit](pi-0.85-adoption.md) — item-by-item release compatibility evidence.

Pi's RPC implementation and the PiDesk source code are the canonical references for current runtime behaviour. The improvement plan is the canonical statement of intended work in this repository.
